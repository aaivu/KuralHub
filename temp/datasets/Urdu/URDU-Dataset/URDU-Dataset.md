# URDU-Dataset (Urdu Speech Emotion Dataset)  

## Dataset Overview

- **Name:** URDU-Dataset  
- **Institution:** NUST and CIIT Universities  
- **Year:** 2018  
- **Authors:** Latif, S., et al.  
- **Homepage:** [GitHub Repository](https://github.com/siddiquelatif/URDU-Dataset)  

## Dataset Content

- **Duration:** Not specified  
- **Sessions:** Multiple TV show recordings  
- **Speakers:** 38 (27 male, 11 female)  
- **Utterances:** 400 total recordings  
- **Language:** Urdu  
- **Source:** TV talk shows  

## Technical Details

- **Format:** Audio recordings  
- **Source:** Extracted from YouTube videos  
- **Recording:** Natural TV show environment  
- **Data Types:** Spontaneous speech  
- **File Naming:** SGX_FXX_EYY format
  - SG: Speaker Gender (M/F)
  - X: Speaker ID
  - XX: File number
  - YY: Emotion label (A,H,N,S)

## Emotional Content

- **Primary Emotions:**  
  - Angry (A)  
  - Happy (H)  
  - Neutral (N)  
  - Sad (S)  

- **Emotion Types:**
  - Natural/spontaneous emotions
  - Unscripted discussions
  - Real-world scenarios
