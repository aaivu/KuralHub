Emotion Recognition from Assamese Speech using MFCC Features and GMM Classifier
Contact
parismita@dibru.ac.in

The Assamese Emotional Speech Corpus comprises recordings from native Assamese speakers, capturing four distinct emotional states: angry, happy, sad, and neutral. This dataset was utilized to investigate emotion recognition using Mel-frequency cepstral coefficients (MFCC) for feature extraction and Gaussian Mixture Model (GMM) classifiers. The research aimed to enhance the accuracy of emotion recognition systems for Assamese speech.

Paper
Emotion Recognition in Standard Spoken Assamese Language Using Support Vector Machine and Ensemble Model
Contact
nupur.choudhury@dbuniversity.ac.in

The Assamese Emotional Speech Dataset comprises recordings from native Assamese speakers, capturing seven distinct emotional states: calm, neutral, anger, sad, happy, surprise, and disgust. This dataset was utilized to investigate emotion recognition using Support Vector Machine (SVM) and Ensemble Models, including Random Forest and Rotation Forest classifiers. The research aimed to enhance the accuracy of emotion recognition systems for Assamese speech, achieving up to 94.40% accuracy with the Rotation Forest Classifier when multiple features were combined.
