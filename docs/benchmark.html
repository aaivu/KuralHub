Speech emotion recognition benchmark: HuBERT, wav2vec 2.0, WavLM and Whisper in 29 languages

Test scores for 11 frozen speech models on 33 speech emotion recognition datasets in 29 languages: 363 runs in all.

Every run uses the same recipe: the pretrained backbone stays frozen, its last-layer features are averaged over time, and a two-layer classification head is trained on a 70/15/15 split of the dataset, using the five shared emotions (anger, happiness, sadness, neutral and fear) that the dataset contains. See section 3 of the paper for details and section 4 for the analysis.

  • Accuracy: share of test clips classified correctly.
  • Macro-F1: F1 averaged over emotion classes, each class counted equally.
  • Weighted-F1: F1 averaged over classes, weighted by how often each class appears.

Download: runs.csv · runs.json · per-run logs on GitHub.

Want another model in these tables? Suggest a checkpoint, or run it with the same recipe and send the logs (how to). New datasets for the benchmark are welcome too.
