# 🗂️ Speech Emotion Recognition (SER) Datasets for Chinese

Welcome to the **Chinese - Mandarin, Southern Min, Gan, Xiang, Jinyu, Hakka** section of KuralHub! <br/>
This directory contains **Speech Emotion Recognition (SER) datasets** available for **Chinese**, along with metadata and access information.

- **🗣 Language Name:** Chinese <br/>
- **🌐 Language Family:** Sino-Tibetan <br/>
