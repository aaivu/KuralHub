# 🗂️ Speech Emotion Recognition (SER) Datasets for Quechua

Welcome to the **Quechua** section of KuralHub! <br/>
This directory contains **Speech Emotion Recognition (SER) datasets** available for **Quechua**, along with metadata and access information.

## 🌍 **Language Information**

- **🗣 Language Name:** Quechua <br/>
- **🌐 Language Family:** One of the world's primary [language families](https://en.wikipedia.org/wiki/Language_family) <br/>
- **🔤 ISO Code:** qu <br/>
- **📍 Major Spoken Countries:** Throughout the central Andes Mountains including Argentina, Bolivia, Chile, Colombia, Ecuador, and Peru <br/>
