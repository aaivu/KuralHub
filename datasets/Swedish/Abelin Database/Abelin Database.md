# Swedish Emotion Speech Database (Abelin Database)

## Dataset Overview
- **Name**: Abelin Database / Swedish Emotion Speech Database
- **Institution**: University of Gothenburg
- **Year**: 2000
- **Authors**: Åsa Abelin
- **Homepage**: [ISCA Archive Paper](https://www.isca-archive.org/speechemotion_2000/abelin00_speechemotion.pdf)

## Dataset Content
- **Total Duration**: Limited information (only known durations: happiness prosody 462-652ms, disgust prosody 690-1037ms for specific stimuli)
- **Speakers**: Single native Swedish male speaker
- **Speech Types**: Single carrier phrase recordings
  - Phrase: "salt sill, potatismos och pannkakor" (salted herring, mashed potatoes and pancakes)

## Technical Details
- **Language**: Swedish
- **Type**: Speech recordings
- **Format**: Tape recorded (specific format not specified)
