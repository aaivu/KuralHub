# Tamil & Malayalam Emotion Database (TaMaR-EmoDB)

## Dataset Overview
- **Name**: TaMaR-EmoDB (Tamil Malayalam Ravula - Emotion Database)
- **Institution**: Not specified
- **Year**: 2019
- **Authors**: 
  - R. Rajan
  - Haritha U.G.
  - Sujitha A.C.
  - Rejisha T. M.
- **Homepage**: [Interspeech 2019 Paper](https://www.isca-archive.org/interspeech_2019/rajan19_interspeech.html)

## Dataset Content
- **Total Duration**: Not specified
- **Speakers**: Not specified
- **Speech Types**:
  - Simulated speech utterances
  - Subjects reading sentences with expressed emotions

## Technical Details
- **Languages**: 
  - Tamil
  - Malayalam
  - Ravula (tribal language)
- **Type**: Speech recordings
- **Features Used**:
  - MFCCs
  - Prosodic features (short-time energy, zero crossing rate)
  - Pitch features (standard deviation, skewness, kurtosis)

## Emotional Content
- **Primary Emotions**:
  - Anger
  - Anxiety
  - Happiness
  - Sadness
  - Neutral

## Research Impact
- **Applications**: 
  - Speech emotion detection
  - Corpus-based prosody analysis
  - Speech synthesis
- **Performance**:
  - Malayalam: Precision 0.78, Recall 0.84
  - Tamil: Precision 0.60, Recall 0.61
  - Ravula: Precision 0.61, Recall 0.53
- **DOI**: 10.21437/interspeech.2019-2034
