# TurEV-DB (Turkish Emotion-Voice Database)  

## Dataset Overview

- **Name:** Turkish Emotion-Voice Database (TurEV-DB)  
- **Institution:** Not specified  
- **Year:** 2020  
- **Authors:** Özer, N., Yildirim, S.  
- **Homepage:** ACL Anthology  

## Dataset Content

- **Duration:** Not specified  
- **Sessions:** Single recording session  
- **Speakers:** 6 amateur actors (3 male, 3 female)  
- **Words:** 82 unique words  
- **Utterances:** 1,735 total tokens  
- **Language:** Turkish  

## Technical Details

- **Format:** 32-bit Float PCM WAV files  
- **Audio:** 44.1 kHz sampling rate  
- **Channel:** Mono  
- **Recording:** Sony Mobile Sound Recorder  
- **Processing:** Denoised using Audacity 2.3.0  
- **Features:**
  - 1,582 statistical features (OpenSmile IS10_paralig)
  - 3 prosodic features (OpenSmile prosodyAcf)
  - 1,738 spectrograms (STFT)
  - 1,738 overlaid spectrograms with prosody

## Emotional Content

- **Primary Emotions:**  
  - Angry  
  - Calm  
  - Happy  
  - Sad
